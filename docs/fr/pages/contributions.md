# **Contributions**

## **Statut du projet**

GeVarLi est **activement maintenu et développé de manière continue**.  
Les contributions de la communauté, retours d'expérience, signalements de bugs et propositions d'améliorations sont les bienvenus !

## **Comment contribuer**

Consultez notre [Guide de contribution](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/blob/main/CONTRIBUTING.md) détaillé disponible à la racine du dépôt.

1. **Signaler un bug** : Utilisez notre [modèle de rapport de bug](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/issues/new?issuable_template=Bug) standardisé sur la Forge IRD.
2. **Proposer une fonctionnalité** : Soumettez vos idées via le [modèle de demande de fonctionnalité](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/issues/new?issuable_template=Feature).
3. **Proposer des modifications de code** :
    * Travaillez sur la branche de développement `develop`.
    * Vérifiez que le pipeline passe les tests à blanc (`snakemake -n --config fastq_dir='.test/reads/'`) et que la documentation compile sans avertissement.
    * Ouvrez une Merge Request vers la branche `develop`.

## **Charte de bonne conduite**

Tous les contributeurs et utilisateurs s'engagent à respecter notre [Charte de bonne conduite](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/blob/main/CODE_OF_CONDUCT.md).

## **Citation**

Si vous utilisez GeVarLi dans vos projets ou publications scientifiques, merci de le citer en utilisant les métadonnées de notre fichier [`CITATION.cff`](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/blob/main/CITATION.cff).

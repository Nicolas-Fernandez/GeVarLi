# **Contributions**

## **Project status**

GeVarLi is **actively maintained and continuously developed**.  
Community contributions, feedback, bug reports, and pull/merge requests are warmly welcomed!

## **How to contribute**

Please refer to our detailed [Contributing Guide](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/blob/main/CONTRIBUTING.md) in the repository.

1. **Report bugs**: Use our standardized [Bug Report template](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/issues/new?issuable_template=Bug) on IRD-Forge.
2. **Propose features**: Submit requests using the [Feature Request template](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/issues/new?issuable_template=Feature).
3. **Submit code changes**:
    * Work on the `develop` branch.
    * Ensure your changes pass Snakemake DAG resolution (`snakemake -n --config fastq_dir='.test/reads/'`) and strict MkDocs build validation.
    * Open a Merge Request against `develop`.

## **Code of Conduct**

All participants are expected to adhere to our [Code of Conduct](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/blob/main/CODE_OF_CONDUCT.md).

## **Citation**

If you use GeVarLi in your research, please cite it using the metadata provided in [`CITATION.cff`](https://forge.ird.fr/transvihmi/nfernandez/GeVarLi/-/blob/main/CITATION.cff).
